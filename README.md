# Sales Performance & Profitability Analysis

## Overview

This project analyzes sales data to understand revenue, cost, profit,
profit margin, regional performance, product performance, sales channels,
and order priorities.

The analysis was performed using Python and focuses on exploratory data
analysis, data preprocessing, feature engineering, and visualization.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Key Analysis

- Data cleaning and preprocessing
- Date transformation
- Data type optimization
- Expense calculation
- Profit margin calculation
- Regional profitability analysis
- Country-level performance
- Item type analysis
- Sales channel analysis
- Order priority analysis
- Profit margin trends over time

## Key Metrics

The project calculates:

- Total Revenue
- Total Cost
- Total Profit
- Expense
- Profit Margin
